## 本篇新词

- 实验单元（experimental unit） 指一次独立观测所对应的最小对象，例如一次任务运行。单元的粒度决定误差条的口径。
- 处理（treatment） 指被改变的因素的某个取值。比较两种配置时，配置就是处理。
- 响应（response） 指被观测的量。它的尺度决定用什么统计量：计数用比例、连续量用均值与分位数。
- 混杂（confounder） 指同时与处理和响应相关的变量。它的存在使观测差异不能被解释为处理的效果。
- 可识别性（identifiability） 指因果效应能否由可观测数据唯一确定。有未观测混杂时不可识别。
- 消融（ablation） 指去掉一个组件后重跑，用以归因该组件的贡献。它是干预而不是观察。
- 最小可检测效应（minimum detectable effect, MDE） 指在给定样本量与功效下能被分辨的最小差异。它按 $1/\sqrt{n}$ 缩小。
- 事前登记（preregistration） 指在跑实验之前写下假设、指标与停止规则。它使多重比较与提前停止的偏差可控。

## 一、【设计原因】

### 1.1 缺陷一：跑了两个方法，差异落在噪声里而结论已经写了

两种配置各跑 30 次，均值差 2.3 个百分点，结论写"配置 B 更优"。

问题在于：同一配置重跑多次的结果本身在波动。若单次运行的标准差足够大，30 次样本下 2.3 个点的差异完全可以由波动产生。

判断标准不是"差异看起来明显"，而是"差异大于这个样本量能分辨的下限"。

### 1.2 缺陷二：消融之后，其他东西也变了

去掉一个组件之后重跑，指标提升了。结论写"该组件有害"。

而在这个改动里，同时被改的还有提示词的长度、工具的数量、上下文占用。其中任何一项都可能是提升的原因。

消融的效力取决于只有一处变化。做不到这一点时，得到的不是归因，是相关性。

### 1.3 缺陷三：比较了十个配置，其中一个是"显著"的

十个配置各与基线比较，其中一个的 p 值小于 0.05，报告写"发现了显著提升"。

十次独立检验中至少一次落在 0.05 以下的概率是 $1 - 0.95^{10} \approx 0.40$——四成的概率什么也没做也会看到"显著"。

::: keypoint 反直觉点
**"显著"这个词在多重比较下会失去含义。** 比得越多，"发现"越多，而这些发现里的大多数是假的。校正不是可选的严谨，它是使结论可用的必要条件。
:::

### 1.4 缺陷四：结果无法被他人重跑

实验跑出来了，别人按论文里的描述重跑，得到不同的数。

原因通常是没记录随机源：采样温度、随机种子、任务顺序、并发度、依赖版本。其中任何一项不同，结果就可能不同。

### 1.5 由此确定的设计目标

1. 先定差异再反推样本：写实验计划时先声明要检测多大的差异。
2. 消融只改一处：多处改动时要么拆成多次实验，要么明确标注为联合效应。
3. 多重比较必须校正：事前登记比较的集合，或使用 FDR。
4. 记录全部随机源：使他人能复现，也使自己能解释波动来源。

**本节要点**

- 判断标准是"差异是否大于可分辨下限"，不是"看起来明显"。
- 消融的效力取决于只有一处变化。
- 多重比较下"显著"会失去含义（十次检验约四成会出现假阳性）。
- 无法重跑通常是没记录随机源。
- 四条目标：先定差异、只改一处、校正比较、记录随机源。

## 二、【直觉】

### 2.1 秤与噪声

用一台有噪声的秤称两件东西。秤的读数每次都在抖，抖动的幅度是它的噪声下限。

- 若两件东西的真实重量差远大于抖动，一次称重就能分辨。
- 若差小于抖动，称一万次取平均也能分辨——平均值的抖动按 $1/\sqrt{n}$ 缩小。

这条直观给出实验设计的核心公式：要分辨多小的差异，就需要多少样本。而它必须在跑之前算，因为跑完之后样本量已经固定。

::: keypoint 反直觉点
**"多跑几次看看"不是设计，是赌博。** 样本量在跑之前就决定了能分辨的下限。跑完再看 p 值，等于让数据决定你要问什么问题。
:::

### 2.2 拆机器

一台机器不工作了，你拆掉一个零件，机器恢复了。这能说明该零件有问题吗？

只有在别的都没动的情况下才能。 如果你同时清了灰、紧了一颗螺丝、换了油，那恢复的原因可能是其中任何一项。

这就是消融的前提：一次只拆一个零件。做不到时，只能说"这一组改动合起来有效"，不能说"因为那个零件"。

### 2.3 一个数字直觉

设单次运行的成功率标准差约 16 个百分点，要用 80% 功效检出差异：

- 检出 10 个点：每组 41 次
- 检出 5 个点：每组 161 次
- 检出 3 个点：每组 447 次
- 检出 1 个点：每组 4019 次

样本量按差异的平方反比增长。 想分辨的差异减半，样本量要翻两番。这条限制了实验的规模：不是"想多准就多准"，而是预算决定了能问多细的问题。

**本节要点**

- 平均值的抖动按 $1/\sqrt{n}$ 缩小，这是样本量公式的来源。
- 样本量必须在跑之前确定。
- 消融一次只拆一个零件。
- 样本量按差异的平方反比增长：差异减半，样本翻两番。

## 三、【严格】

### 3.1 定义

::: theorem 定义 6.2.1（实验单元、处理与响应）
一次实验由三元组 $(U, T, Y)$ 描述：$U$ 是实验单元集合，$T$ 是处理（被改变的因素取值），$Y: U \to \mathbb{R}$ 是响应函数。

第 $i$ 个单元在接受处理 $t$ 时的响应记作 $Y_i(t)$。**因果效应**定义为

$$
\tau = \mathbb{E}[Y_i(1) - Y_i(0)] .
$$

注意 $Y_i(0)$ 与 $Y_i(1)$ 对同一个 $i$ 至多只能观测到一个——这是因果推断的根本困难。
:::

::: theorem 定义 6.2.2（混杂与可识别性）
变量 $C$ 是**混杂**，当且仅当 $C$ 同时与 $T$ 相关且与 $Y$ 相关：

$$
C \not\perp T \quad \text{且} \quad C \not\perp Y \mid T .
$$

若存在未观测的混杂，则称 $\tau$ **不可识别**：仅凭 $(T, Y)$ 的观测分布无法唯一确定 $\tau$。
:::

::: theorem 定义 6.2.3（消融）
给定系统的组件集合 $\{c_1, \dots, c_k\}$，**消融** $A_j$ 是把 $c_j$ 移除后的系统。消融的效应为

$$
\tau_j = \mathbb{E}[Y(A_j) - Y(A_{\text{full}})] .
$$

**消融是干预**：它改变系统，而不是观察已有的差异。
:::

::: theorem 定义 6.2.4（最小可检测效应）
在显著性水平 $\alpha$、功效 $1-\beta$、每组样本量 $n$、响应标准差 $\sigma$ 下，**最小可检测效应**为

$$
\mathrm{MDE} = (z_{1-\alpha/2} + z_{1-\beta}) \cdot \sigma \sqrt{\frac{2}{n}} .
$$

它随 $n$ 按 $1/\sqrt{n}$ 缩小。
:::

::: theorem 定义 6.2.5（族错误率）
对 $m$ 个原假设各做一次水平为 $\alpha$ 的检验，**族错误率**（至少拒绝一个真原假设的概率）为

$$
\mathrm{FWER} = 1 - (1-\alpha)^m .
$$

当检验不独立时，该式是上界（Bonferroni）或近似（独立性下取等号）。
:::

::: theorem 定义 6.2.6（事前登记）
**事前登记**是一份在观测数据之前写下的四元组 $(H, Y, m, \text{stop})$：假设集合 $H$、主指标 $Y$、比较次数 $m$、停止规则 $\text{stop}$。

登记的作用是把 $m$ 与 $\text{stop}$ 从"事后决定"变成"事前固定"，从而使校正与停止规则有意义。
:::

### 3.2 命题

::: theorem 命题 6.2.1（未观测混杂使因果效应不可识别）
若存在未观测混杂 $U$，则观测到的条件均值差 $\mathbb{E}[Y \mid T=1] - \mathbb{E}[Y \mid T=0]$ 不等于 $\tau$，且其偏差不能被观测数据修正。

**证明.** 由全期望公式，

$$
\mathbb{E}[Y \mid T=1] - \mathbb{E}[Y \mid T=0] = \tau + \underbrace{\bigl(\mathbb{E}[U \mid T=1] - \mathbb{E}[U \mid T=0]\bigr) \cdot \beta_U}_{\text{选择偏差}},
$$

其中 $\beta_U$ 是 $U$ 对 $Y$ 的效应。因 $U$ 与 $T$ 相关，括号内非零，故观测差等于 $\tau$ 加上一个非零项。又因 $U$ 未被观测，该括号不可从观测数据估计。

↓ **为什么能这么写？** 全期望公式把观测差分解为因果效应与选择偏差两部分，而后者依赖未观测的 $U$。

$\blacksquare$

::: keypoint 这条结论决定了实验设计的必要性
**如果混杂可以被事后修正，就不需要做实验了。** 正因为未观测混杂的偏差无法事后修正，才必须在设计阶段用随机化把它消掉。
:::
:::

::: theorem 命题 6.2.2（随机化消除混杂）
若处理 $T$ 由随机分配决定且与 $(U, Y(0), Y(1))$ 独立，则观测差等于 $\tau$。

**证明.** 由独立性，$\mathbb{E}[U \mid T=1] = \mathbb{E}[U \mid T=0]$，故命题 6.2.1 中的选择偏差项为零。又由独立性 $\mathbb{E}[Y(t) \mid T=t] = \mathbb{E}[Y(t)]$，故观测差为 $\mathbb{E}[Y(1)] - \mathbb{E}[Y(0)] = \tau$。

↓ **为什么能这么写？** 随机分配使处理与所有协变量（含未观测）独立，选择偏差项因此消失。

$\blacksquare$

::: keypoint 随机化也消除未知的混杂
**这是它相对于"控制已知变量"的关键优势：** 控制已知变量只消除已知混杂。随机化同时消除未知混杂，因为独立性对全部协变量成立。代价是它要求能随机分配处理——在 agent 实验里指随机化任务顺序与随机种子。
:::
:::

::: theorem 命题 6.2.3（最小可检测效应随样本量按平方根缩小）
$\mathrm{MDE}(n) \propto n^{-1/2}$。因此要把可检测差异缩小一半，样本量需增至 4 倍。

**证明.** 由定义 6.2.4，$\mathrm{MDE} = (z_{1-\alpha/2} + z_{1-\beta})\sigma\sqrt{2/n}$。$\sqrt{2/n} = \sqrt 2 \cdot n^{-1/2}$，故 $\mathrm{MDE} \propto n^{-1/2}$。

令 $\mathrm{MDE}(n_2)/\mathrm{MDE}(n_1) = 1/2$，得 $\sqrt{n_1/n_2} = 1/2$，即 $n_2 = 4n_1$。

↓ **为什么能这么写？** 比例关系直接来自公式形式，倍数的解由开方得到。

$\blacksquare$

**数值**：$\sigma = 16$ 个百分点、$\alpha = 0.05$、功效 0.8 时，检出 10 个点需每组 41 次，检出 5 个点需 161 次，检出 3 个点需 447 次，检出 1 个点需 4019 次。
:::

::: theorem 命题 6.2.4（多重比较的假阳性膨胀）
$m$ 次独立检验的族错误率为 $1-(1-\alpha)^m$，它随 $m$ 单调增且当 $m \to \infty$ 时趋于 1。

**证明.** 单次检验不误拒的概率为 $1-\alpha$。独立性使 $m$ 次都不误拒的概率为 $(1-\alpha)^m$。故至少误拒一次的概率为 $1-(1-\alpha)^m$。该式随 $m$ 单调增（因 $1-\alpha < 1$），且 $m \to \infty$ 时 $(1-\alpha)^m \to 0$。

↓ **为什么能这么写？** 补事件的概率由独立性相乘得到。

$\blacksquare$

**数值**：$\alpha = 0.05$ 时，$m = 5$ 给出 0.226，$m = 10$ 给出 0.401，$m = 20$ 给出 0.642。**比二十个配置，即使全部无效，也有约六成概率看到至少一个"显著"。**
:::

::: theorem 命题 6.2.5（消融的归因效力取决于单变量改动）
若消融 $A_j$ 相对 $A_{\text{full}}$ 除移除 $c_j$ 之外还有其他差异 $\delta$，则 $\tau_j$ 不能归因于 $c_j$。

**证明.** 观测差为 $\mathbb{E}[Y(A_j) - Y(A_{\text{full}})] = \tau_j + \tau_\delta$，其中 $\tau_\delta$ 是其他差异的效应。若不能证明 $\tau_\delta = 0$，则观测差中包含与 $c_j$ 无关的项，故不能归因。

↓ **为什么能这么写？** 差异可分解为各部分效应之和。只要存在非零的 $\tau_\delta$，归因就不成立。

$\blacksquare$

::: keypoint 联合效应也是一种合法结论
**做不到单变量改动时，结论应当写成"这一组改动合起来有效"，而不是"因为某个组件"。** 前者是可验证的（重跑同一组改动），后者不是。把不可归因的结果写成归因结论，是实践中最常见的过度声明。
:::
:::

::: theorem 命题 6.2.6（可复现需要固定全部随机源）
设结果 $R$ 是所有随机源 $(s_1, \dots, s_k)$ 的函数。若某个 $s_i$ 未被记录且未被固定，则他人无法保证复现 $R$。

**证明.** 取两个仅 $s_i$ 不同的运行。由假设 $R$ 依赖 $s_i$，两次结果可以不同。他人重跑时无从知道原运行使用的 $s_i$ 取值，故无法保证得到相同结果。

↓ **为什么能这么写？** 复现要求两次运行的全部输入一致，而未记录的随机源不满足这一条件。

$\blacksquare$

**推论**：可复现的记录清单就是随机源的清单——采样参数、种子、任务顺序、并发度、依赖版本、环境变量。
:::

### 3.3 本节要点

**本节要点**

- 因果效应的定义要求同一单元的两个结果，而二者至多观测到一个（定义 6.2.1）。
- 未观测混杂使观测差不等于因果效应，且偏差不可事后修正（命题 6.2.1）。
- 随机化消除全部混杂（含未观测），因为它使处理与协变量独立（命题 6.2.2）。
- MDE 按 $n^{-1/2}$ 缩小，差异减半需要 4 倍样本（命题 6.2.3）。
- 族错误率随比较次数增长，20 次比较约 0.64（命题 6.2.4）。
- 消融的归因效力取决于单变量改动（命题 6.2.5）。
- 可复现要求固定并记录全部随机源（命题 6.2.6）。

## 四、【回到直觉】

- 定义 6.2.1 说的：因果是"同一单元在两个处理下的结果之差"，而这两个结果只能看到一个。实验设计就是在绕开这个限制。
- 命题 6.2.1 说的：未观测的混杂没法事后修。所以要么在设计阶段消掉它，要么承认结论只是相关。
- 命题 6.2.2 说的：随机化不只是"公平分配"，它消掉了连你自己都不知道的混杂。
- 命题 6.2.3 说的：样本量在跑之前就定死了能分辨多小的差异。想分辨得更细，只能加样本，不能靠多看几眼。
- 命题 6.2.4 说的：比得越多，"显著"越不值钱。十个配置里冒出一个显著结果，概率上很正常。
- 命题 6.2.5 说的：一次只改一处，否则只能报"这组合有效"。
- 命题 6.2.6 说的：把随机源列成清单并记录。别人重跑不出来，通常不是他笨，是你没写。

**本节要点**

- 因果是两个潜在结果之差，实验设计用于绕开不可观测性。
- 未观测混杂不可事后修正。
- 随机化消除未知混杂。
- MDE 由样本量决定，且必须在跑之前算。
- 多重比较必须校正。
- 消融一次只改一处，否则报联合效应。
- 随机源清单就是可复现清单。

## 五、【工具箱】

### 5.1 样本量与功效

检出效应 $\Delta$ 所需每组样本量为

$$
n \approx \frac{2\sigma^2 (z_{1-\alpha/2} + z_{1-\beta})^2}{\Delta^2} .
$$

用途：实验设计的第一步。反过来，给定 $n$ 可算出 MDE，用于判断"这次实验能问出什么"。

### 5.2 多重比较的两种校正

Bonferroni：把显著性水平除以比较次数，即用 $\alpha/m$。它控制 FWER，代价是功效下降。

Benjamini-Hochberg（FDR）：把 $m$ 个 p 值升序排列 $p_{(1)} \le \dots \le p_{(m)}$，取最大的 $k$ 使 $p_{(k)} \le \frac{k}{m} q$，拒绝前 $k$ 个。它控制错误发现比例，功效高于 Bonferroni。

选择：确认型比较用 Bonferroni，探索型扫描用 FDR。

### 5.3 序贯检验

边跑边看会抬高假阳性率。若必须提前停止，用 mSPRT 控制任意时刻的错误率：

$$
\Lambda_n = \sqrt{\frac{\tau^2}{\tau^2 + n\sigma^2}} \exp\left(\frac{n^2 \bar{X}_n^2}{2\sigma^2(\tau^2 + n\sigma^2)}\right) .
$$

数值：固定样本检验在真实零假设下边跑边看，假阳性率可达 30% 以上。mSPRT 保持名义水平。

### 5.4 随机化的实现

随机分配的实现要点有三条：种子可记录、分配可校验（事后能复算每人拿了什么处理）、分层（在已知的强混杂变量上分层随机，以进一步降低方差）。

在 agent 实验里，随机化通常作用于任务顺序与随机种子，而不是任务内容。

### 5.5 事前登记的内容

按定义 6.2.6 登记四元组，另加两条：主指标与次指标的划分、排除规则（哪些运行会被剔除，以及依据）。

排除规则尤其重要——它是事后调整结果的主要途径，必须事前写定。

**本节要点**

- 样本量公式是实验设计的第一步。
- 确认型比较用 Bonferroni，探索型用 FDR。
- 需要提前停止就用 mSPRT。
- 随机化要有种子、可校验、可分层。
- 事前登记要含主次指标划分与排除规则。

### 7.3 统计段：先算 MDE，再看结果

统计段的顺序是先算 MDE 再读结果。反过来（先看结果再解释）会让"MDE"退化成事后辩解的素材。

```js
// 定义 6.2.4：最小可检测效应
export function mde(n, sigma, alpha = 0.05, power = 0.8) {
  const z = quantileNormal(1 - alpha / 2) + quantileNormal(power)
  return z * sigma * Math.sqrt(2 / n)
}

// 工具箱 5.1：由目标差异反推每组样本量
export function sampleSize(delta, sigma, alpha = 0.05, power = 0.8) {
  const z = quantileNormal(1 - alpha / 2) + quantileNormal(power)
  return Math.ceil(2 * sigma * sigma * z * z / (delta * delta))
}

/** 标准正态分位数（Acklam 逼近）。

@param p 累积概率 @returns 分位数 */
export function quantileNormal(p) {
  const a = [-3.969683028665376e1, 2.209460984245205e2, -2.759285104469687e2, 1.383577518672690e2, -3.066479806614716e1, 2.506628277459239]
  const b = [-5.447609879822406e1, 1.615858368580409e2, -1.556989798598866e2, 6.680131188771972e1, -1.328068155288572e1]
  const c = [-7.784894002430293e-3, -3.223964580411365e-1, -2.400758277161838, -2.549732539343734, 4.374664141464968, 2.938163982698783]
  const d = [7.784695709041462e-3, 3.224671290700398e-1, 2.445134137142996, 3.754408661907416]
  const plow = 0.02425
  if (p < plow) {
    const q = Math.sqrt(-2 * Math.log(p))
    return (((((c[0] * q + c[1]) * q + c[2]) * q + c[3]) * q + c[4]) * q + c[5]) / ((((d[0] * q + d[1]) * q + d[2]) * q + d[3]) * q + 1)
  }
  if (p > 1 - plow) {
    const q = Math.sqrt(-2 * Math.log(1 - p))
    return -(((((c[0] * q + c[1]) * q + c[2]) * q + c[3]) * q + c[4]) * q + c[5]) / ((((d[0] * q + d[1]) * q + d[2]) * q + d[3]) * q + 1)
  }
  const q = p - 0.5
  const r = q * q
  return (((((a[0] * r + a[1]) * r + a[2]) * r + a[3]) * r + a[4]) * r + a[5]) * q /
    (((((b[0] * r + b[1]) * r + b[2]) * r + b[3]) * r + b[4]) * r + 1)
}
```

### 7.4 多重比较校正

两种校正的适用面不同：确认型比较用 Bonferroni，探索型扫描用 FDR。

```js
// 定义 6.2.5：族错误率
export function familyErrorRate(m, alpha) {
  return 1 - Math.pow(1 - alpha, m)
}

// 工具箱 5.2：Bonferroni —— 控制 FWER，代价是功效下降
export function bonferroni(pvalues, alpha) {
  const threshold = alpha / pvalues.length
  return { threshold, rejected: pvalues.map((p, i) => (p <= threshold ? i : -1)).filter((i) => i >= 0) }
}

// 工具箱 5.2：Benjamini-Hochberg —— 控制错误发现比例，功效更高
export function benjaminiHochberg(pvalues, q = 0.05) {
  const m = pvalues.length
  const order = pvalues.map((p, i) => ({ p, i })).sort((x, y) => x.p - y.p)
  let k = 0
  order.forEach((o, idx) => { if (o.p <= ((idx + 1) / m) * q) k = idx + 1 })
  return { k, rejected: order.slice(0, k).map((o) => o.i) }
}
```

### 7.5 执行记录段：随机化

随机化要能事后复算：同一种子必须给出同一分配结果，这是它可校验的前提。

```js
// 工具箱 5.4：可记录种子的随机分配（Fisher-Yates）
export function randomize(units, seed) {
  const rng = rngFrom(seed)
  const a = [...units]
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1))
    ;[a[i], a[j]] = [a[j], a[i]]
  }
  return { order: a, seed }
}

/** 可复现的伪随机数发生器（mulberry32）。

@param seed 种子 @returns 返回 [0,1) 的函数 */
export function rngFrom(seed) {
  let s = seed >>> 0
  return function next() {
    s = (s + 0x6D2B79F5) >>> 0
    let t = s
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
}
```

### 8.3 评审一份实验设计的六个问题

1. 要检测多大的差异？ 没写就是没有样本量依据。
2. 样本量是怎么定的？ 应当是反推出来的，不是"能跑多少就跑多少"。

### 9.2 失败模式

- （1）检查放在装载期（L9 位置放错）。 样本量的计算在实验开始前做了一次，而中途因为运行失败补跑了几次，样本量变了而没有重算 MDE。表现是"补跑之后结论变强，但那个强度对应的样本量并不成立"。修正：把样本量作为实验记录的一部分，补跑时重算。

- （2）前提会变（L9）。 命题 6.2.2 的随机化以"处理分配与协变量独立"为前提。若分配的实现有缺陷（例如按任务名的字典序轮流分配），独立性的前提就不成立。修正：分配可校验——事后能复算每个单元拿了什么处理，并检验分配与已知协变量的相关性。

- （3）差异落在噪声里就下结论。 没有 MDE 的依据。

- （4）消融时改了多处。 结论是相关性而不是归因。

- （5）多配置比较不校正。 "显著"是多重比较的产物。

- （6）边跑边看且用固定样本检验。 假阳性率可到 30% 以上。

- （7）随机源记录不全。 他人无法复现，自己也解释不了波动来源。

- （8）事后修改排除规则。 最隐蔽的结果调整方式。

- （9）把次指标当主指标报告。 多个指标里挑最好看的那个，等价于未校正的多重比较。

- （10）分层之后不重新算功效。 分层把每组样本摊薄，各层的功效低于总功效。

**本节要点**

- 决策表覆盖 11 种情形。
- 失败模式十条，前两条是位置放错与前提会变。
- 最隐蔽的是"事后改排除规则"与"把次指标当主指标"。

## 十、仍未解决

- 消融的交互效应。 单变量改动给出的是主效应。组件之间存在交互时，逐个消融的结论之和可能大于联合效应。
- 随机化的成本。 分层随机需要更多样本，而在 agent 实验里样本本身就是昂贵资源。
- 外部效度。 实验结论能否迁移到别的任务集，缺少定量判据。
- 配对设计的可用性。 同一任务上比较两个处理可以大幅降低方差，但要求两次运行的初始状态完全一致。
- 长尾指标的统计。 分位数之间的比较所需样本量远大于均值之间的比较。
- 停止规则的事前设定。 停止规则一旦写定就不能改，而实验中途发现效应量估计错误时这个约束会变成负担。

**本节要点**

- 逐个消融之和不一定等于联合效应。
- 分层随机会摊薄功效。
- 外部效度缺少定量判据。
- 配对设计受初始状态一致性限制。
- 分位数的比较需要更多样本。
- 停止规则写定后不可调整。

## 十三、只记一句话 + 记忆锚点

只记一句话：

> **实验的可信度取决于三件事：差异大于噪声、归因没有混入别的变化、别人按你记的东西能重跑。**

本篇的所有结论都能从这一句话推出来：说"差异大于噪声"，就有 MDE 与样本量公式。说"归因没混入别的变化"，就有随机化、单变量消融与多重比较校正。说"别人能重跑"，就有随机源清单与事前登记。

如果读完只记得一句话，就记它。其余细节都可以由它推回来。

**记忆锚点**

- 一个问题：要检测多大的差异？（没写就没有样本量依据）
- 三个必须：必须随机化、必须只改一处、必须校正比较。
- 两个公式：$\mathrm{MDE} \propto n^{-1/2}$、$\mathrm{FWER} = 1-(1-\alpha)^m$。
- 三个数字：m=10 的族错误率 0.401。σ=16、Δ=10 需 41 次。Δ=5 需 161 次（约 4 倍）。
- 一条清单：随机源清单就是可复现清单。
