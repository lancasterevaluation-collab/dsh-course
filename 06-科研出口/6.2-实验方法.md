## 读完这一篇你会知道什么

1. **样本量随效应减小而急剧增加**：算例里 $\Delta = 10$ 需要 41 个样本，$\Delta = 5$ 需要 161，$\Delta = 3$ 需要 447，而 $\Delta = 1$ 需要 4019。
2. $\Delta = 5$ 与 $\Delta = 10$ 的样本量之比是 3.93 倍（接近 $2^2 = 4$）。
3. MDE：算例里 $n = 40$ 时能检测的最小效应是 10.02。
4. 族错误率：算例里 5 次比较是 0.226，10 次是 0.401，20 次是 0.642。
5. 两种校正：Bonferroni 阈值（$m = 6$ 时 0.0083）比 BH 更保守——算例里 BH 拒绝了 4 个假设，Bonferroni 只拒绝了 1 个。
6. 选择偏差：算例里偏差达 2。
7. 工业界怎么做：A/B 测试、灰度、以及"如何避免自欺"。
8. 学术界：假设检验、多重比较校正、实验设计。

## 一、为什么"跑一次对比"不算实验

### 1.1 样本不够

"新版本比旧版本好 3%"——**但每个版本只跑了 5 次。** 这个差异完全在噪声范围内。

### 1.2 多重比较

试了 20 种配置，**其中一种"显著更好"**。在 20 次比较里，出现一次假阳性的概率是 64%（算例数字），所以这个"发现"大概只是运气。

### 1.3 挑样本

"我们看了表现最好的那批任务"——**这批任务是按表现挑出来的**，结论自然乐观（算例里偏差达 2）。

这三件事分别对应：**样本量、多重比较、选择偏差。**

## 二、实验设计的三个量

| 量 | 回答 | 决定 |
|---|---|---|
| **样本量** | 要跑多少次 | 结论的可靠性 |
| **族错误率** | 做多次比较时的整体风险 | 要不要校正 |
| **偏差** | 结论与真值的系统差距 | 结论是否有效 |

**三者都是"做之前"要算的**（与 6.1 的预注册一致）。

## 三、怎么做

### 3.1 样本量

$$
n \approx \frac{2\sigma^2 (z_{1-\alpha/2} + z_{1-\beta})^2}{\Delta^2}
$$

（$\sigma$ 为标准差，$\Delta$ 为要检测的效应，$\alpha$ 为显著性水平，$\beta$ 为第二类错误率。）

算例实测（$\sigma = 16$）：

| 要检测的效应 $\Delta$ | 所需样本量 |
|---|---|
| 10 | **41** |
| 5 | **161** |
| 3 | **447** |
| **1** | **4019** |

这张表是本篇最重要的数字：**效应减半，样本量涨约 4 倍**（算例验算：$161/41 = 3.93$）。

含义：**"想检测更小的改进"的成本是平方级增长的。** 这与 2.1 的"轮数翻倍成本变 4 倍"是同一类非线性。

实践判据：**先问"多小的差异才值得关心"**，再算样本量。如果为了检测 1 分的差异需要 4019 次实验，那这个差异可能本来就不值得检测。

这条判据能省掉大量无效工作：**很多"提升 1%" 的优化，其验证成本远高于收益。**

### 3.2 最小可检测效应

反过来，给定样本量能检测多小的效应：

算例实测：**$n = 40$、$\sigma = 16$ 时，MDE 是 10.02**。

MDE 的实用价值：**它告诉你"这个实验能看见什么"。** 跑了 40 次就宣称"没有差异"是不成立的——你只能宣称"没有大于 10 的差异"。

正确的表述方式：

| 错误表述 | 正确表述 |
|---|---|
| "两个方案效果一样" | "在 $n = 40$ 下，无法检测到大于 10 的差异" |

这条表述纪律与 6.3 的置信区间是同一件事：**任何结论都要带上它的不确定性范围。**

### 3.3 多重比较

试很多种配置时，**假阳性的概率会累积**。算例给出的族错误率：

| 比较次数 $m$ | 族错误率（$\alpha = 0.05$） |
|---|---|
| 5 | **0.226** |
| 10 | **0.401** |
| **20** | **0.642** |

$$
\text{FWER} = 1 - (1-\alpha)^m
$$

读法：**做 20 次比较时，有 64% 的概率至少出现一次"显著"的假结果。** 所以"我从 20 个配置里找到了一个更好的"几乎必然包含假阳性。

两种校正方法：

| 方法 | 做法 | 特点 |
|---|---|---|
| **Bonferroni** | 阈值除以 $m$ | 保守，控制 FWER |
| **BH（Benjamini-Hochberg）** | 按 p 值排序后逐步比较 | **控制 FDR，检出更多** |

算例实测：

| 方法 | 结果 |
|---|---|
| Bonferroni 阈值（$m = 6$） | **0.0083**（= 0.05 / 6） |
| Bonferroni 拒绝集合 | **[0]**（只拒绝 1 个） |
| **BH 拒绝集合（$q = 0.05$）** | **[0, 1, 2, 3]**（拒绝 4 个） |

**BH 比 Bonferroni 检出更多**，这是它的价值：Bonferroni 控制"至少一次假阳性"的概率（FWER），BH 控制"假阳性占被拒总数的比例"（FDR）。 后者在探索性研究里更合适。

选择建议：

| 场景 | 用哪个 |
|---|---|
| 结论会被单独依赖（例如发布决策） | Bonferroni 或更保守 |
| 探索性筛选（后续还要验证） | BH |
| **任何情况** | **报告做了多少次比较** |

最后一行是底线：**即使不做校正，也必须报告比较次数**——否则读者无法判断结论的可信度。

### 3.4 随机化与可复现

算例验证了两条：**"同种子的分配可复现"为 `true`**，且分配结果是 `t1, t5, t3, t2, t4`。

两条要求：

| 要求 | 做法 |
|---|---|
| **随机化** | 用随机方式分配任务到各组（避免系统性差异） |
| **可复现** | 记录随机种子，使分配可重现 |

两者不矛盾：**用固定种子 + 随机算法**，既有随机化的统计性质，又可复现。

算例还验证了"随机源检查（全记）为 `true`"：**所有影响结果的随机源都要被记录**。

"全记随机源"为什么重要：**只要有一个随机源没记，结果就不可复现**——这与 2.7 的"模型可见即已记录"是同一条纪律在实验层面的体现。

这里有一个 agent 系统特有的难点：**模型输出本身是随机的**（见 2.1 的 LLM 调用差别、7.4 的采样）。所以实验记录必须包含采样参数，否则无法复现。

### 3.5 选择偏差

算例实测：**"选择偏差 @ τ=0, uGap=0.4, β=5" 得到 `{observed: 2, bias: 2}`**。

选择偏差的含义：**当你按某个标准挑选样本时，被选中的样本在那个维度上会系统性偏离总体。**

两种常见形式：

| 形式 | 例子 |
|---|---|
| **按结果挑选** | "我们看表现最好的任务" |
| **幸存者偏差** | "我们看还在运行的实例" |
| **事后选择** | "这个配置在事后看是最好的" |

算例里 bias 为 2：**观察到的值与真值差了 2**。

避免手段：

| 手段 | 说明 |
|---|---|
| **预注册** | 实验前定好分析方式（6.1） |
| **随机化** | 消除系统性差异 |
| **留出验证集** | 选择在一个集合上做，验证在另一个上 |
| **报告全部** | 包括没被选中的 |

"留出验证集"是最有效的一条：**它在超参优化与自我改进（4.5）里都是必需的**（否则等于用训练数据当测试数据）。

## 四、特殊情况与处理技巧

| 情况 | 为什么 | 处理 |
|---|---|---|
| 样本不足就下结论 | 未算样本量 | 先算再跑 |
| 宣称"没有差异" | 未给 MDE | 表述为"无法检测大于 X 的差异" |
| 试了很多配置 | 未校正 | 校正或至少报告次数 |
| 结论不可复现 | 随机源未记录 | 记录全部随机源与种子 |
| 结论过于乐观 | 选择偏差 | 留出验证集 |
| 效应很小 | 样本量爆炸 | 先问"这个差异值得检测吗" |
| 多次实验消耗巨大 | 未用配对设计 | 配对设计可降低方差 |
| 实验间互相影响 | 未隔离 | 独立会话 + 独立资源 |

"配对设计"值得了解：**如果能让同一个任务同时跑两种方案，那么任务本身的难度差异就被抵消了**，所需样本量可大幅下降。这是降低实验成本最有效的手段之一。

## 五、工业界的做法（可照做）

### 5.1 A/B 测试的工程实践

| 要素 | 做法 |
|---|---|
| **分流** | 按用户/会话稳定哈希分流 |
| **样本量** | 实验前算好，不到不结论 |
| **指标** | 主指标 + 护栏指标（与 3.6 一致） |
| **时长** | 覆盖完整的周期性波动 |
| **多重比较** | 明确主指标，其余为探索 |
| **停止规则** | **事先定好**，不随时偷看 |
| **事后** | 报告效应量与置信区间，不只看 p 值 |

"不随时偷看"值得强调：**反复查看结果并在"显著"时停止，会把假阳性率抬高数倍**（这是一类被充分研究过的问题）。正确做法是定好样本量，跑满再看。

**"报告效应量与置信区间"** 是 6.3 的核心内容：p 值只说"有没有差异"，效应量说"差多少"。

### 5.2 实验基础设施

| 组件 | 作用 |
|---|---|
| **任务集** | 固定的评测样本（见 6.3） |
| **随机种子管理** | 可复现 |
| **日志** | 记录全部尝试（6.1） |
| **自动分析** | 统一口径，避免手工挑选 |
| **护栏检查** | 防止优化一处伤害另一处 |

"自动分析"很重要：**手工分析容易引入选择偏差**（人会挑好看的结果）。把分析写成脚本，口径就固定了——这与本课程"可机械验证"的主张一致。

### 5.3 参数与设计起点

| 参数 | 推荐 | 依据 |
|---|---|---|
| 显著性水平 | 0.05 | 惯例 |
| 检验力 | 0.8 | 惯例（$\beta = 0.2$） |
| 主指标 | 1 个 | 避免多重比较 |
| 探索指标 | 单独报告 | 用 BH 校正 |
| 样本量 | 按公式算 | 不拍脑袋 |
| 随机种子 | 固定并记录 | 可复现 |
| 验证集 | 与选择集分离 | 避免偏差 |

### 5.4 一份可落地的实施清单

1. **先算样本量**：给定 $\Delta$、$\sigma$、$\alpha$、$\beta$。
2. 写清 MDE：结论表述要带可检测范围。
3. 主指标唯一：其余作为探索并校正。
4. 报告比较次数：不做校正也要报。
5. 随机化 + 种子：并全记随机源。
6. 跑满再停：不随时偷看。
7. 留出验证集：选择与验证分离。
8. 配对设计：能配对就配对。
9. 自动分析：口径固定成脚本。
10. 报告效应量：不只看 p 值。

## 六、学术界的结论

### 6.1 假设检验的两种错误

| 错误 | 含义 | 代价 |
|---|---|---|
| **第一类（假阳性）** | 没有效应却报有 | 做了无效的改动 |
| **第二类（假阴性）** | 有效应却没发现 | 错过了改进 |

两者的权衡由检验力（$1-\beta$）决定：**要提高检验力就得加大样本量。**

实践含义：**"检验力 0.8"意味着有 20% 的真实效应会被漏掉**。这解释了为什么"没发现差异"不等于"没有差异"。

对本课程的直接应用：**在做"方案 A 是否比 B 好"的比较时（见 6.3 的 benchmark），必须报告样本量与 MDE**，否则读者无法判断阴性结果的含义。

### 6.2 多重比较校正

多重比较是统计学里被研究得最充分的问题之一，主要方法：

| 方法 | 控制 | 特点 |
|---|---|---|
| **Bonferroni** | FWER | 简单，最保守 |
| **Holm** | FWER | Bonferroni 的改进，更有效 |
| **BH** | **FDR** | 探索性研究常用 |
| **Permutation** | 依分布 | 不依赖分布假设 |

"Holm"值得知道：**它比 Bonferroni 更有效（拒绝更多），同时同样控制 FWER**。所以在需要控制 FWER 时，Holm 优于 Bonferroni。

本课程为什么用 Bonferroni 作对照：**它是最简单、最容易手算的**，而算例要展示的正是"校正会减少拒绝数"这个现象。

### 6.3 实验设计的历史结论

Fisher 奠定的实验设计三原则至今有效：

| 原则 | 作用 |
|---|---|
| **随机化** | 消除系统性差异 |
| **重复** | 估计噪声 |
| **区组（配对）** | **消除已知的干扰因素** |

"区组"就是 3.5 里说的配对设计：**把已知会带来差异的因素（例如任务难度）固定住，只比较关心的变量。**

**在 agent 评测里，区组化的形式是"同一批任务跑所有方案"**——这样任务难度的影响就被消掉了。

### 6.4 可复现性危机与对策

多个领域都经历过"大量已发表结果无法复现"的问题。总结出的对策与本篇一致：

| 对策 | 说明 |
|---|---|
| **预注册** | 假设与方法前置 |
| **报告全部尝试** | 含阴性 |
| **共享数据与代码** | 可重跑 |
| **报告效应量与区间** | 不只看显著性 |
| **记录随机源** | 可复现 |

对本课程的直接应用：**算例本身是可运行的**（`node examples/*.mjs`），这正是"共享代码"这一条的实践形式。讲义里写的数字全部来自这些算例，而不是手算或估算。

## 七、理论：两个公式

### 7.1 样本量

$$
n \approx \frac{2\sigma^2 (z_{1-\alpha/2} + z_{1-\beta})^2}{\Delta^2}
$$

算例实测（$\sigma = 16$）：$\Delta = 10$ 得到 **41**、$\Delta = 5$ 得到 161、$\Delta = 3$ 得到 447、$\Delta = 1$ 得到 4019。

关键比例关系：

$$
n \propto \frac{1}{\Delta^2}
$$

算例验证：**$\Delta = 5$ 与 $\Delta = 10$ 的样本量之比是 3.93 倍**（接近 4）。

含义：**想检测一半的效应，需要四倍的样本。** 这是"精细优化验证成本高昂"的定量依据。

### 7.2 族错误率

$$
\text{FWER} = 1 - (1-\alpha)^m
$$

算例实测：$m = 5$ 得到 **0.226**、$m = 10$ 得到 0.401、$m = 20$ 得到 0.642。

近似：当 $\alpha$ 小时，$\text{FWER} \approx m\alpha$。**$m = 20$、$\alpha = 0.05$ 时约 1.0**——实际值 0.642（因为公式是精确的）。两者都是"做很多比较必然出现假阳性"的定量表达。

可检查的判据：**报告里必须写明做了多少次比较。** 没有这个数字，读者无法评估假阳性风险。

## 十、算例

算例实现了本篇的样本量计算、多重比较校正与偏差分析。

```powershell
cd D:\dsh-course
node examples/sa13_experiment.mjs        # 全部函数的运行结果
node examples/test_sa13_experiment.mjs   # 数字回归断言
```

它做到的事：

- **样本量**（$\Delta = 10/5/3/1$ 分别得到 41 / 161 / 447 / 4019）。
- MDE（$n = 40$、$\sigma = 16$ 得到 10.02）与样本量比例（3.93 倍）。
- 族错误率（$m = 5/10/20$ 得到 0.226 / 0.401 / 0.642）。
- 两种校正的对照：Bonferroni 阈值 0.0083、拒绝 [0]。BH 拒绝 [0,1,2,3]。
- 选择偏差（`{observed: 2, bias: 2}`）与同种子分配可复现（`true`）、随机源全记（`true`）。

这一篇只要记住一句：实验前必须算三个量——**样本量**（效应减半要四倍样本，检测 1 分差异要 4019 次）、族错误率（20 次比较有 64% 概率出现假阳性）、以及偏差（按结果挑样本会系统性乐观）。而结论永远要带上效应量与不确定性范围，不能只说"显著"。
