# 第七卷 · 大模型基模

> **这一卷解决什么**：前六卷都在"用"模型。这一卷往下扎一层——模型是什么、它的成本从哪来、它的不确定从哪来、以及你的设计里**哪些部分应该等模型变强而不是现在硬做**。
>
> **定位**：与 CS336（Language Modeling from Scratch）最基础的部分对齐，但只取**与 agent 工程衔接所必需**的那些。每一篇都以"这如何影响你的 harness 设计"收尾。

## 本卷包含

| 篇 | 主题 | 它回答的工程问题 |
|---|---|---|
| 7.1 | token 与分词 | 为什么上下文按 token 算、中文与代码为什么贵 |
| 7.2 | Transformer 与注意力的成本 | 为什么上下文是平方成本、KV cache 为什么值钱 |
| 7.3 | 预训练、微调与对齐 | 什么时候该提示、该检索、该微调 |
| 7.4 | 采样与确定性 | 为什么两次输出不同，以及怎么让评测可复现 |
| 7.5 | 推理的成本结构 | 首 token 延迟、吞吐与批处理怎么决定架构 |
| 7.6 | 能力评测 | benchmark 怎么测能力、怎么被污染、怎么自己测 |

## 与 CS336 的对应关系

CS336 从零实现一个语言模型，链条是：分词 → Transformer → 训练 → 并行与 GPU → scaling laws → 数据 → 对齐 → 评测。

本卷取其中**与工程衔接**的部分，并明确不取什么：

| CS336 的主题 | 本卷的处理 |
|---|---|
| 分词（BPE） | **取**：token 计量与语言差异（7.1） |
| Transformer 架构 | **取**：注意力成本与 KV cache（7.2） |
| 训练与优化器 | **取**：预训练改变了什么（7.3） |
| GPU 与核函数 | **不取**：属于模型训练工程，与 harness 无关 |
| 并行训练 | **不取**：同上 |
| scaling laws | **取一句**：为什么"等模型变强"是合理策略（7.3） |
| 数据 | **略讲**：只讲数据如何影响能力边界（7.6） |
| 对齐（SFT / RLHF） | **取**：三种改变手段的边界（7.3） |
| 推理与解码 | **取**：采样、延迟与缓存（7.4、7.5） |
| 评测 | **取**：能力的测量与污染（7.6） |

## 怎么读这一卷

这一卷**不要求你会训练模型**。它的目标是让你能：

- 看懂模型侧同事说的话（"这个要重训""KV cache 打满了""这个 benchmark 被污染了"）；
- 判断一个需求该在提示层、检索层、微调层还是系统层解决；
- 在设计成本敏感的功能时，知道钱花在哪、以及怎么让它便宜一个数量级。

**前置**：第 2 卷（模型层与最小闭环）与第 3 卷（上下文压缩、可观测）。这一卷是它们的"为什么"。

## 运行本卷的算例

本卷算例用 PyTorch，需要一个项目级虚拟环境（已加入 `.gitignore`，不会进仓库）。

```powershell
cd D:\dsh-course
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe torch --index-url https://download.pytorch.org/whl/cpu
npm run test:cs336
```

三条使用说明：

- 没有 NVIDIA GPU 时用 **CPU 版**（上面 `--index-url` 指向的就是 CPU 轮子）。CPU 上小规模训练完全跑得动，本篇所有数字都产自 CPU。
- **依赖 NVIDIA 的部分本机跑不了**：Triton / FlashAttention 核函数、DDP / FSDP 多卡并行、大规模 scaling law 实验。这类内容给原版代码，并补一个本机可跑的缩小版等价实验，讲义里会明确标注。
- 没建 `.venv` 时 `npm run test:cs336` **会跳过而不是报错**——缺本地环境不该让文档门禁变红。

**本卷要点小结**

- 本卷是前六卷结论的"为什么"：token 计量、平方成本、采样不确定性、成本结构、评测局限。
- 六篇各自对应一类工程判断：计量（7.1）、成本（7.2、7.5）、手段选择（7.3）、可复现（7.4）、可信度（7.6）。
- 全部算例在本机 CPU 上真跑，数字来自真实输出；依赖 NVIDIA 的部分给出原版代码与本机缩小版等价实验。
- 不取 GPU 核函数与并行训练：那是模型训练工程，与 harness 无关。
