## 读完这一篇你会知道什么

1. **分辨率**：100 个样本测出的 70%，95% 区间是 [0.6042, 0.7811]——宽 18 个百分点。
2. **样本量公式**：要检出 70% → 74% 的提升，需要每组约 1974 个样本。
3. **噪声下限**：400 个样本时，同配置跑两次的差异就有 3.2 个百分点。
4. **污染效应**：10% 的测试样本落进训练数据，分数虚高 3 个百分点——与"一次有效优化"同量级。
5. **指标陷阱**：90% 正类的数据上，一个什么都没做的模型能拿到 **准确率 0.90、F1 0.95**，只有均衡准确率停在 0.50。
6. **工程上要补什么**：评测集版本化、污染检测、多运行取分布。

## 一、为什么需要知道它

### 1.1 用小评测集得出的"提升"

在一份 100 条样本的评测集上，改动后准确率从 70% 升到 74%，于是上线。实际上 100 条样本的置信区间宽达 18 个百分点——**这 4 个百分点连噪声的边都没碰到**。

### 1.2 分数很高，线上很差

评测集里的题目在训练数据里出现过，模型"记得答案"。10% 的污染率就足以让分数虚高 3 个百分点，而这个量级**正好等于一次有效优化的收益**。

### 1.3 一个"什么都没做"的模型看起来很能干

数据 90% 是正类。一个永远回答"是"的模型：准确率 0.90、F1 0.95。**两项常用指标都漂亮得可以写进报告**，而它一个负类都没识别出来。

这三件事各自对应一个可计算的量：**区间宽度、污染率、指标定义**。

## 二、评测要回答什么

一次可信的评测要同时回答三个问题：

1. **多少分**——以及这个分数的**误差范围**。
2. **这个分数能分辨多大的差异**——分辨率下限。
3. **它测的是不是真能力**——有没有污染、指标是否合适。

只回答第一个问题的评测，得到的数字无法支撑任何决策。

## 三、怎么做

### 3.1 分辨率：样本量决定这个分数有多准

用 Wilson 区间（比正态近似更稳，小样本与极端比例下也可用）：

```python
def wilson_interval(successes, n, z=1.959963985):
    """Wilson 置信区间。"""
    p = successes / n
    denom = 1 + z * z / n
    center = (p + z * z / (2 * n)) / denom
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / denom
    return max(0.0, center - half), min(1.0, center + half)
```

算例实测（准确率固定 70%）：

| 样本量 | 95% 区间 | 宽度 |
|---|---|---|
| 100 | [0.6042, 0.7811] | **0.1769** |
| 400 | [0.6534, 0.7428] | 0.0895 |
| 1000 | [0.6709, 0.7276] | 0.0567 |
| 4000 | [0.6856, 0.7140] | 0.0284 |
| 16000 | [0.6929, 0.7071] | 0.0142 |

**样本量翻 4 倍，区间宽度约减半**（算例验证：$0.1769 / 0.0895 = 1.98$）。因为宽度按 $1/\sqrt{n}$ 收缩——**要让精度提高一倍，样本量要翻四倍**。

区间宽度的直接含义：它就是"这份评测能分辨的最小差异"。宽度 0.1769 意味着，任何小于 18 个百分点的差异都无法与噪声区分。

### 3.2 样本量：要检出多大的提升

反过来问：想看一次 4 个百分点的提升，要多少样本？

$$
n = \frac{(z_{\alpha/2} + z_{\beta})^2 \cdot \left[p_1(1-p_1) + p_2(1-p_2)\right]}{(p_1 - p_2)^2}
$$

算例实测（功效 0.8、显著性 0.05）：

| 想检出的提升 | 每组所需样本 |
|---|---|
| 70% → 74%（4 个百分点） | **1974** |
| 70% → 72%（2 个百分点） | 8077 |
| 70% → 90%（20 个百分点） | 59 |

这条表决定了评测集的规模：想要小改动可见，评测集必须上千条。只想要"大改动可见"，几百条也够。

反过来说：如果你手上只有 100 条样本，你能可靠区分的只有**巨大**的差异（约 20 个百分点级别），中间的一切都是猜测。

### 3.3 噪声下限：先测噪声，再判断差异

**同配置跑两次，得到的差异就是纯噪声。** 这个数必须先测出来，否则无从判断改动是否有效。

算例实测（$n = 400$，真实准确率 0.72，跑 20 次）：

| 量 | 数值 |
|---|---|
| 20 次运行的均值 | 0.7221 |
| 最小 / 最大 | 0.6850 / 0.7700 |
| **配对差值的均值** | **0.0318**（即噪声下限） |
| 理论量 $\sqrt{2p(1-p)/n}$ | 0.0317 |

经验值与理论吻合。**结论**：400 条样本的噪声下限是 3.2 个百分点——想用它检出 4 个百分点的提升，等于在噪声边缘试探。这也正是 3.2 的公式给出 1974 条的原因。

操作口径：任何"变好了多少"的结论，先扣掉噪声下限再讨论。

### 3.4 污染：测试样本落进训练数据

$$
\text{测得准确率} = (1 - \text{污染率}) \cdot \text{真实准确率} + \text{污染率} \cdot 1.0
$$

算例实测（真实准确率 0.70）：

| 污染率 | 测得准确率 | 虚高 |
|---|---|---|
| 0% | 0.7000 | 0 |
| 5% | 0.7150 | 0.0150 |
| 10% | 0.7300 | **0.0300** |
| 25% | 0.7750 | 0.0750 |

**10% 的污染造成的虚高（3 个百分点）与"一次有效优化"（4 个百分点）是同一量级。** 这意味着：**一个被污染的评测集，会把"什么都没做"报告成"有明显改进"。**

污染检测的实用手段：

- **时间切分**：评测样本的创建时间必须晚于训练数据截止时间。
- **n-gram 重叠**：检查评测样本的长片段是否出现在训练语料里。
- **改写不变性**：把题目换个说法重新问，若分数大跌，说明原来在考记忆。
- **答案扰动**：把选项顺序打乱，若分数大跌，说明在考位置记忆。

### 3.5 指标选择：不平衡数据上的陷阱

算例构造了一个 1000 条、90% 正类的数据集，然后让模型**永远回答"是"**：

| 指标 | 值 |
|---|---|
| 准确率 | 0.90 |
| 精确率 | 0.90 |
| 召回率 | 1.00 |
| **F1** | **0.95** |
| **均衡准确率** | **0.50** |

这里有一个反直觉的事实：不只是准确率虚高，**F1 也虚高**（0.95 甚至比准确率还高）。因为精确率与召回率在这个数据上都接近 1，F1 自然高。

**唯一暴露问题的是均衡准确率**（0.50 = 随机水平），因为它对两类一视同仁。

这条结论的工程含义：

- 不平衡数据上，**报告准确率或 F1 都不足以说明能力**。
- 至少同时报告**每类召回**或**均衡准确率**。
- 更好的是**按类别分别给出样本量与区间**，避免把一个大类的表现当成整体表现。

## 四、特殊情况与处理技巧

| 情况 | 为什么 | 处理 |
|---|---|---|
| 用 100 条样本下结论 | 区间宽 18 个百分点 | 按 3.2 的公式先算所需样本量 |
| 改动效果在噪声内 | 没测噪声下限 | 同配置跑两次估下限，再判断 |
| 评测分数突然大涨 | 可能是污染 | 查时间切分与 n-gram 重叠 |
| 指标漂亮但线上差 | 数据不平衡或指标不合适 | 报告均衡准确率与每类召回 |
| 多次运行结果波动 | 采样噪声（见 7.4） | 固定参数 + 多次运行取分布 |
| 评估集被反复使用 | 会逐渐过拟合到它上面 | 留出从不查看的保留集 |
| 只看平均分 | 掩盖了子群体的失败 | 按子群体分别报告 |

一条通用技巧：**评测的三个数字必须先确定**——样本量、噪声下限、污染检查。缺任何一个，结论都不能用于决策。

## 五、理论：三件事同时决定可信度

一个评测结论的可信度由三件事共同决定，缺一不可：

1. **样本量**决定分辨率下限（$1/\sqrt{n}$ 收缩）。
2. **噪声下限**决定"差异是否真实"（采样与实现波动）。
3. **污染率与指标选择**决定"测的是不是你想测的东西"。

用算例的数字串起来：400 条样本 → 噪声下限 3.2%。要检出 4 个百分点需要约 1974 条。10% 污染会造成 3 个百分点的虚高。

这三个数彼此不能替代：样本量再大也消不掉污染。污染再干净也消不掉小样本的宽区间。区间再窄也救不了选错的指标。

由此得到一条实践准则：

> **报告一个提升时，必须同时给出：样本量、置信区间、噪声下限、以及污染检查的结论。** 缺项的结论只能当作线索，不能当作依据。

## 六、工程化

| 项 | 内容 |
|---|---|
| 评测集版本化 | 每次改动用了哪个版本要可追溯，否则无法复现分数 |
| 时间切分 | 评测样本的创建晚于训练截止时间 |
| 污染检测 | 自动跑 n-gram 重叠与改写不变性检查 |
| 样本量核算 | 改动前先算"要检出这个提升需要多少样本" |
| 噪声下限 | 定期用同版本跑两次，记录当次噪声下限 |
| 保留集 | 从不查看、只在上线决策时用一次的样本 |
| 指标组合 | 主指标 + 每类召回 + 均衡准确率，三者一起报 |
| 子群体分析 | 按用户群体 / 任务类型分别报告，避免平均数掩盖失败 |

## 七、练习

### 第一题：判断这个结论能不能用

一份报告：评测集 150 条，改动前准确率 68%，改动后 73%，结论是"提升了 5 个百分点，建议上线"。

要求：

- 算出评分 68% 在 150 条样本上的 95% 区间宽度。
- 用 3.2 的公式算出要检出 5 个百分点需要多少样本。
- 给出你需要的另外两个数字（提示：噪声下限与污染检查），并说明为什么缺了它们这个结论不能用。

### 第二题：设计一份不会被指标骗倒的评测

场景：你要评估一个"从工单文本里抽取字段"的功能，数据里 92% 的工单不含需要抽取的字段。

要求：

- 说明为什么不能只报准确率，并给出你会报的指标组合。
- 算出在这份数据上"永远回答没有该字段"的模型的各项指标（准确率、每类召回、均衡准确率）。
- 设计一个能发现"模型其实没在抽取、只是学会了回答没有"的检验，并说明它的输入与判定规则。

提示：第三问的关键是构造一个**只含正类的最小集合**，在这上面测召回——它的分数骗不了人。
