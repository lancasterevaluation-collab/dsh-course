> 对应讲义：`4.1 记忆`、`4.2 技能`。作答方式见 `../../../作业引导.md` 第六节。
>
> 把答案写进 `kit/answers/a-memory.json`（从 `a-memory.template.json` 复制）。

---

## 第一组：写入判定（12 项）

对每一项给出 `decision`（`write` / `skip`）、`kind`（`fact` / `preference` / `inference`；`skip` 时可为 `null`）、以及 `reason`。

**`reason` 必须提到三个过滤器之一**（判分器做包含检查）：

| 过滤器 | 判据 |
|---|---|
| 跨会话 | 它在下一个会话里还有用吗 |
| 可验证 | 它是可验证的事实，还是推测（推测必须带来源） |
| 临时 | 它在一周后还成立吗 |

---

**m1.** 用户在这次会话里说："把那个 `build` 目录删掉。"

**m2.** 观察到的项目事实：这个仓库用 pnpm，而不是 npm。

**m3.** 模型的一次推断：用户可能更喜欢简短的回复。

**m4.** 会话开始时写入的当前时间戳。

**m5.** 用户主动告知：他在 UTC+8 时区。

**m6.** 这次任务使用的临时目录路径。

**m7.** 用户明确说过："以后都用简体中文回答我。"

**m8.** 模型从行为推断：用户对 Rust 的熟悉程度可能较低（用户从未声明过）。

**m9.** 项目约定：这个仓库的构建命令是 `pnpm build`。

**m10.** 这次会话使用的 git 分支名。

**m11.** 用户明确说过："以后所有提交都不要带 emoji。"

**m12.** 上一次任务的一个中间结论，而它在后续会话里已被新的结论取代。

## 第二组：技能描述（6 项）

下面是六条**当前写得不好**的技能描述。对每一条给出两样：

- `description`：改写成**触发条件**（回答"何时用"）；
- `doesNotApplyWhen`：一条**不适用条件**。

**`description` 不得以「关于」「本技能」开头**（那说明写的是主题而不是触发条件）。

**sk1.** 当前描述："关于代码重构。"

**sk2.** 当前描述："测试相关。"

**sk3.** 当前描述："这个技能用于处理各种情况下的提交。"

**sk4.** 当前描述："当用户要求重构 TypeScript 的可选链时。"（过窄）

**sk5.** 当前描述："写文档。"

**sk6.** 当前描述："本技能描述了如何处理并发问题。"

## 第三组：有界处置（2 项）

对每一项给出 `action`（你要做什么）与 `reason`（依据）。

**b1.** 记忆已满。新候选与两条已有条目**高度相似**（相似度超过阈值）。

**b2.** 记忆已满。新候选与**任何**已有条目都不相似。

## 判据与答案表（作答之后再看）

| 判据 | 权重 |
|---|---|
| 12 个写入判定正确 | 8 |
| 类别与理由（理由需提到过滤器之一） | 3 |
| 6 条技能描述写成触发条件且含不适用条件 | 3 |
| 2 个有界处置与讲义一致 | 1 |

| id | decision | kind | 依据 |
|---|---|---|---|
| m1 | skip | null | 一次性意图，不满足"跨会话有用" |
| m2 | write | fact | 可验证的项目事实，跨会话有用 |
| m3 | write | inference | 推测必须带来源，且它是跨会话的偏好线索 |
| m4 | skip | null | 临时（一周后不成立） |
| m5 | write | fact | 用户声明的事实，跨会话有用 |
| m6 | skip | null | 临时 |
| m7 | write | preference | 用户声明，跨会话有用 |
| m8 | write | inference | 推测类：写入必须带来源标注 |
| m9 | write | fact | 可验证的项目约定 |
| m10 | skip | null | 临时 |
| m11 | write | preference | 用户声明，跨会话有用 |
| m12 | skip | null | 已被取代，不再是当前事实 |

**三处值得说明的地方**：

- **m1 与 m7 的差别**：两者都是用户说的，而 m1 是一次性动作（做完就结束），m7 是一条长期偏好。**判据是"下一个会话里还有用吗"**。
- **m3 与 m8 都是 `inference`**：它们可以写入，但**必须带来源标注**（否则推测会在后续被当成事实，那就是记忆污染）。
- **m12 是 `skip` 而不是"更新已有条目"**：写入层的职责是拒绝过时信息；"取代"是存储层的动作（`supersededBy`）。
