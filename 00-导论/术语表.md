# 术语表

> 本表规定本课程全部文档的**统一译法**与**首次出现形式**。
>
> 用法：写作时查本表；新术语出现时登记进来（这是交付检查的第 7 项）。
> 形式约定：首次出现写「中文（English）」，之后可只用中文；缩写首次出现写「中文全称（English Full Name，ABBR）」。
> 与 Kubernetes 中文文档的约定一致之处：字段名、命令、路径用反引号；术语保持一致；英文排比中的逗号改顿号。

## 七、本课程自造的术语

| 术语 | 含义 |
|---|---|
| 锚点 | 编号的形式化结果（理论锚点，theory anchor）；分 TA-xx（评测侧）与 SA-xx（系统侧） |
| 代际 | harness 的演进阶段（Gen-0 到 Gen-8） |
| 判据 | 可运行的检查项；每条判据有名字与失败条件 |
| 数字回归 | 断言讲义中的关键数字的测试；改错公式会立刻失败 |
| 分层语体 | 按层区分写作语体的规定（见 0.5 第三节） |
| 只记一句话 | 每篇末尾的一句提问；全篇结论都从它推出来 |
| 基准卡九字段 | 名称、版本、测什么、任务集、判定、环境、指标、已报分数、已知缺陷 |

## 八、容易混用的十组词

| 不要混用 | 区分依据 |
|---|---|
| 会话 vs 对话 | 会话有生命周期与 id；对话只是消息往来 |
| 超时 vs 截止时间 | 前者是相对量，后者是绝对时刻 |
| 检查点 vs 快照 | 前者是恢复流程里的位置，后者可独立存在 |
| 抑制 vs 删除 | 前者可逆 |
| 消融 vs 删除组件 | 前者换成中性替代 |
| 置信度 vs 概率 | 前者是加权计数（本课程的定义），不是概率 |
| 信度 vs 效度 | 前者是"可重复吗"，后者是"测的是那个量吗" |
| 污染 vs 过拟合 | 前者是训练数据含评测数据 |
| 饱和 vs 已解决 | 前者是"分数失去区分度" |
| 提议 vs 动作 | 前者是可评审的差异，不是执行 |
